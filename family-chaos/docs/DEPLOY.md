# פרסום לאינטרנט (Render, מסלול חינמי) — מהטלפון

הכל מוכן במאגר: `render.yaml` בשורש המאגר מגדיר שירות **Free** באזור פרנקפורט (הכי קרוב לישראל), מהענף `ccr-64ced051-a2t8s8`, מהתיקייה `family-chaos`.
לא צריך מפתחות, סודות או משתני סביבה. Render מוסיף לבד את הכתובת הציבורית (`RENDER_EXTERNAL_URL`), וממנה נוצרים ה־QR וקישורי ההצטרפות.

## צעד־אחר־צעד (Chrome בטלפון, בערך 5 דקות)

1. פתח את **dashboard.render.com** והתחבר עם **GitHub**. אשר את ההרשאה ש־Render מבקש.
   **אל תוסיף כרטיס אשראי.** הוא לא נדרש למסלול החינמי, ובלעדיו אין חיוב על חריגה (ראה מגבלות למטה).
2. אם Render מבקש גישה למאגרים, בחר **Only select repositories**, ואז `Hillel-s-Experiments`.
3. בלוח הבקרה: **New** (או **+**), ואז **Blueprint**.
4. בחר את המאגר `hillelyivaxman-dot/Hillel-s-Experiments`.
   * **Branch:** בחר `ccr-64ced051-a2t8s8`. זה חשוב, כי ענף ברירת המחדל של המאגר לא מכיל את המשחק.
   * **Blueprint Name:** `family-chaos`.
5. Render יציג שירות אחד, `family-chaos`, עם **Plan: Free**. ודא שכתוב Free ולחץ **Deploy Blueprint** (או **Apply**).
6. חכה 2–5 דקות לבנייה. בלוגים תופיע שורה כמו:
   `FAMILY CHAOS server on http://localhost:10000  public: https://family-chaos-xxxx.onrender.com`
7. הכתובת שלך מופיעה בראש דף השירות: `https://family-chaos-xxxx.onrender.com`.

### אם מסך ה־Blueprint לא מאפשר לבחור ענף
**New**, ואז **Web Service**, ובחר את המאגר. מלא כך:
* Branch: `ccr-64ced051-a2t8s8`
* Root Directory: `family-chaos`
* Runtime: Node
* Build Command: `npm ci --include=dev && npm run build`
* Start Command: `node dist/server/index.js`
* Instance Type: **Free**
* Health Check Path (תחת Advanced): `/health`

## בדיקה ראשונה (שני טלפונים ומחשב)

1. **במחשב או בטלוויזיה:** פתח `https://family-chaos-xxxx.onrender.com/host`. אחרי זמן חוסר פעילות הכניסה הראשונה יכולה לקחת עד דקה, כי השרת החינמי "מתעורר".
2. **בכל טלפון:** סרוק את ה־QR (או היכנס לכתובת, ואז "הצטרף מהטלפון" והקלד את הקוד). בחר כינוי ודמות ולחץ **כניסה למשחק**.
3. במחשב לחץ **▶ יאללה, מתחילים!**. ברירת המחדל היא קרב מתנגשים.
4. **בטלפון:** אגודל שמאל בכל מקום בחצי השמאלי הוא הג'ויסטיק. הכפתור הימני הוא הסתערות (DASH). מומלץ לסובב את הטלפון לרוחב.
5. כדי לבדוק "רשתות שונות": טלפון אחד על Wi-Fi והשני על 4G/5G (כבה בו את ה־Wi-Fi).

### מה לבדוק ולדווח לי (אלה הדברים שלא יכולתי לבדוק בלי מכשירים אמיתיים)
- [ ] ה־QR נסרק מהמסך ופותח את דף ההצטרפות.
- [ ] הג'ויסטיק מגיב מהר. האם הוא גדול או קטן מדי?
- [ ] אגודל על הג'ויסטיק ואצבע על כפתור בו־זמנית (בקארטינג: היגוי + גז).
- [ ] הרטט עובד ב־Galaxy. ב־iPhone אין תמיכה ברטט בדפדפן, וזה צפוי.
- [ ] נעילת מסך הטלפון לכמה שניות ופתיחה: הטלפון חוזר לאותו שחקן.
- [ ] מעבר Wi-Fi ל־4G באמצע משחק.
- [ ] המסך לא נכבה באמצע משחק (Wake Lock).

## מגבלות המסלול החינמי (בדקתי בנובמבר 2026 דרך חיפוש; האתר של Render עצמו חסום מסביבת העבודה שלי)

| מגבלה | ערך | מה זה אומר אצלנו |
|---|---|---|
| שינה | אחרי 15 דק' בלי תעבורה נכנסת | הכניסה הראשונה אחרי הפסקה לוקחת עד ~דקה. בזמן משחק השלטים שולחים כל הזמן, אז השרת לא נרדם |
| שעות מופע | 750 לחודש לכל ה־workspace | מספיק לשירות אחד שרץ כל החודש (744 שעות). אם אין עוד שירותים חינמיים, אין בעיה |
| תעבורה | 5GB לחודש (ירד מ־100GB ב־2026) | הפריימים דחוסים: בערך 2–8MB לשעת משחק למסך בבדיקה עם בוטים, ויותר במשחק אמיתי. כל טלפון מוריד ~130KB באתר. מספיק לעשרות ערבי משחק בחודש |
| חריגה מהתעבורה | $0.15 לג'יגה, **רק אם יש כרטיס בחשבון** | לכן לא מוסיפים כרטיס |
| זיכרון/מעבד | 512MB, מעבד חלקי | מספיק לחדרים משפחתיים. לא מיועד לאלפי משתמשים |
| הפעלה מחדש | בכל פריסה או התעוררות | חדרים פעילים נמחקים. הטלפונים מתחברים מחדש ומקבלים "החדר לא נמצא", ופותחים חדר חדש |

כדי לעקוב אחרי הצריכה, `https://…onrender.com/api/info` מראה חדרים, חיבורים ו־MB שנשלחו (לפני דחיסה) מאז ההפעלה האחרונה.

## משחק בבית בלי אינטרנט (חלופה חינמית לגמרי)
```bash
cd family-chaos && npm install && npm run build && npm start
```
פתח במחשב `http://localhost:8787/host`. ה־QR מפנה אוטומטית לכתובת של המחשב ברשת הביתית. כל הטלפונים צריכים להיות על אותו Wi-Fi.
